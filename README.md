## Как начать

1. Скачайте установщик Windows со страницы [последнего выпуска](https://github.com/Frommer-droid/VK-message-history/releases/latest) и установите приложение.
2. Запросите архив данных ВКонтакте с историей сообщений.
3. Откройте приложение, выберите папку с файлами `messages*.html` или перетащите её в окно.
4. Выберите папку для результата и нажмите **«Начать конвертацию»**.
5. Откройте `conversation_chat_view.html` в браузере. Файл `style_chat_view.css` должен оставаться рядом с ним.

Приложение работает на Windows 10/11 x64. Интернет для самой конвертации не нужен.

## Что сохраняется

- Сообщения, авторы, даты и переносы строк.
- Подписи вложений и ссылки HTTP(S), если они есть в экспорте. Вложения находятся под соответствующими сообщениями.
- Порядок сообщений из нескольких файлов `messages*.html`, в том числе из вложенных папок.

Медиафайлы не скачиваются и не встраиваются в итоговую страницу. Для открытия ссылки может потребоваться доступ к сайту-источнику. При повторной конвертации прежний результат сохраняется, а новые HTML и CSS получают числовой суффикс.

## Запуск из исходников

Установите Python 3.12 и зависимости в проектное окружение:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\pythonw.exe process_all_vk.pyw
```

Настройки сохраняются в `%APPDATA%\VK-message-history\ChatConverter_settings.json`. Подробности сборки и проверок — в [DEVELOPER.md](DEVELOPER.md).
