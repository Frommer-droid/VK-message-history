# 👨‍💻 Руководство Разработчика

## 📂 Структура Проекта

- **`process_all_vk.pyw`**: Основной скрипт приложения (PySide6).
- **`tests/`**: Проверки сохранности файлов и отзывчивости окна при обработке.
- **`app/`**: Исходный код приложения.
    - **`version.py`**: Логика управления версиями.
    - **`ui/theme/`**: Общая тема One Dark: палитра, масштаб и глобальная таблица стилей.
- **`Build_Tools/`**: Скрипты и конфигурации для сборки.
    - **`VK-message-history.spec`**: Спецификация PyInstaller.
    - **`VK-message-history.iss`**: Установщик Windows (Inno Setup).
    - **`post_build.py`**: Очистка и организация после сборки.
- **`VERSION`**: Файл, содержащий текущий номер версии.
- **`00_CrRel.pyw`**: Скрипт создания релиза (архивирует сборку).
- **`00_Move.pyw`**: Скрипт обновления локальной портативной версии.

## 🚀 Как собрать (Build)

1. **Предварительные требования**:
   - Python 3.10+
   - Создайте проектное окружение: `py -3.12 -m venv .venv`.
   - Установите зависимости: `.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt`.
   - Запустите проверки: `.\.venv\Scripts\python.exe -m unittest discover -s tests -v`.
2. **Сборка**:
   - Запустите `Build_Tools/SpecCompiler.pyw` через проектный `.venv\Scripts\pythonw.exe`. Сборщик использует минимальный доверенный `PATH`.
   - `.spec` останавливает сборку при обнаружении бинарников из посторонних каталогов и комплектует корневой MSVC runtime из PySide6.
   - Для проверки frozen imports предусмотрен `Build_Tools/frozen_smoke.py` через флаг окружения `VK_FROZEN_SMOKE_BUILD=1`; проверьте stdout, stderr и код завершения собранного smoke `.exe`.
   - Для проверки всей конвертации в console-сборке установите `VK_FROZEN_DIAGNOSTIC_BUILD=1` и запустите полученный `.exe` с аргументами `--smoke-conversion <папка источника> <папка вывода>`. Режим завершает процесс кодом 0 или 1 и печатает ошибки в stderr.
3. **Результат**:
   - `post_build.py` переносит папку сборки в корень проекта как `VK-message-history/`; приложение не запускается автоматически. Пользователю нужна вся папка с `.exe` и `_internal`.
   - `Build_Tools/VK-message-history.iss` собирается через установленный Inno Setup 6 (`ISCC.exe`). Установщик создаётся из готовой папки приложения, исключая личный `ChatConverter_settings.json`.

При конвертации промежуточные TXT получают уникальные имена. Если в папке уже есть итоговые HTML/CSS, новая пара получает суффикс `_2`, `_3` и так далее. Конвертация выполняется в рабочем потоке Qt; закрытие окна откладывается до её завершения.
При неудаче диалог показывает первую ошибку и полный список ошибок в раскрываемых подробностях.
Настройки сохраняются в `%APPDATA%\VK-message-history\ChatConverter_settings.json`; при первом запуске прежний файл рядом с портативным EXE или в рабочей папке исходников читается как источник для переноса настроек.

Интерфейс применяет `app.ui.theme.apply_theme(app)` сразу после создания `QApplication`; роли кнопок заданы через `objectName`. Дополнение для виджетов конвертера находится в конце `app/ui/theme/styles.py`.

Парсер сохраняет текст, переносы строк `<br>`, подписи вложений и безопасные HTTP(S)-ссылки. Ссылки других типов отображаются только как текст. Медиафайлы не встраиваются в итоговый HTML, поэтому доступность вложений зависит от исходного сайта. Промежуточные TXT служат только для чтения человеком; итоговый HTML строится из структурированных записей в памяти.

## 📦 Как выпустить релиз (Release)

1. **Анализ изменений**: Проверьте, что изменилось с последнего релиза.
2. **Обновление версии**:
   - Отредактируйте файл `VERSION`.
   - Отредактируйте `FROZEN_VERSION` в `app/version.py`.
   - Отредактируйте `AppVersion` в `Build_Tools/VK-message-history.iss`.
3. **Обновление документации**:
   - Обновите `RELEASE_NOTES.md`.
   - Обновите `README.md`, если изменились функции.
4. **Сборка**: Запустите процесс сборки.
5. **Проверка**: Протестируйте собранное приложение неинтерактивным frozen-smoke, затем соберите установщик из этой папки и проверьте его состав.
6. **Дистрибуция**:
   - Запустите `00_Move.pyw` для обновления локальной папки Portable Soft.
   - Запустите `00_CrRel.pyw` для создания архива релиза на Рабочем столе.

## 📜 Версионирование

Мы следуем Семантическому Версионированию (Major.Minor.Patch).
- **Major**: Ломающие изменения.
- **Minor**: Новые функции (обратная совместимость).
- **Patch**: Исправления ошибок. 

Номер версии хранится в `VERSION`, дублируется в `app/version.py` для frozen-сборки и в сценарии установщика.
